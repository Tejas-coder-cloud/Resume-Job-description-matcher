# Resume-JD Matcher

AI-powered Resume–Job Description Matcher built using **SBERT, Cosine Similarity, Gemini AI, and Streamlit**.

## Features

* Semantic resume matching using SBERT embeddings
* Multilingual resume analysis
* Skill gap detection
* AI-generated resume improvement suggestions
* Salary prediction based on role and experience
* Gemini-powered AI assistant
* Downloadable analysis reports
* Secure authentication with SHA-256 and MongoDB

## Tech Stack

* Python
* Streamlit
* Sentence Transformers (SBERT)
* Gemini 2.5 Flash
* MongoDB Atlas
* PDFPlumber
* LangDetect

## How It Works

1. Upload Resume (PDF)
2. Extract text and detect language
3. Generate SBERT embeddings
4. Compare skills using Cosine Similarity
5. Identify matched and missing skills
6. Generate AI-powered recommendations

## Performance

* Accuracy: **92.5%**
* Precision: **89.7%**
* Recall: **96.0%**
* F1 Score: **92.8%**
